# Ecozyon Tech

Corporate website for Ecozyon Tech built with React, Vite, and Tailwind CSS.

## Getting Started

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.

## Architecture

This project follows a Feature-Sliced Design (FSD) architecture adapted for React.
- `src/app`: Global settings, routing, providers.
- `src/pages`: Route pages.
- `src/layouts`: UI layouts (Navbar, Footer, etc.).
- `src/features`: Feature-specific modules.
- `src/shared`: Reusable UI components.
- `src/core`: Core configurations and utilities.
